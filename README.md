# 🧠 Math for Programmers: My 12-Week Journey

A structured journey to master mathematics for creative programming, AI, and system design.

## 🚀 Goals
- Relearn math the *programmer’s way* — by coding it.
- Build intuition for logic, optimization, and AI.
- Document progress week-by-week.

## 🗂️ Structure
Each folder contains:
- Notes and key takeaways
- Code experiments and mini projects
- Visualizations or notebooks
